# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

WMSproxy is an Android app that reads WMS, WMTS, ArcGIS REST and XYZ tile services and
serves them as XYZ tiles on loopback, for navigation apps such as DMD2 that cannot address
them themselves.

## Read first

- `.github/architecture.md`: the modules, the tile request path, how a service is read,
  the stores and their files, and the catalogue pipeline.
- `.github/decisions.md`: the reasons behind the design. Check it before changing
  anything it covers.
- `.github/overview.md`, `.github/features.md`, `.github/stackinfo.md`.
- `docs/usage.md`: the user guide. `README.md` links only into `docs/`.

## Building and testing

The project is not built locally. CI builds every push:

- `check.yml` (every branch except `main`): `./gradlew --continue lintDebug test assembleDebug assembleRelease`.
  The debug APK is uploaded as the `app-debug` artifact.
- `build.yml` (`main` only): lint, tests, the signed release, and the `dev` pre-release
  the in-app updater installs from.
- `catalog.yml`: see below.

Use `test`, not `testDebugUnitTest`. `:core` is a plain JVM module, and the Android
variant task does not reach it. Only `:core` and `:tool` have tests (JUnit 4, backtick
names). A single test class runs with
`./gradlew :core:test --tests 'de.codevoid.wmsproxy.core.LibraryMatchTest'`.

## Invariants

- `:core` has no Android dependency, so all of it stays testable with plain JUnit.
- A failed upstream request, or one that returns something other than a raster image,
  is answered with a 502. Never with a blank tile.
- `directBlocker()` in `core/DmdLayers.kt` decides whether a layer goes to DMD directly
  or through the proxy. A new `Rewrite` blocks direct use until DMD is shown to handle it.
- `ServiceReader` is the only way a service is read, by the app and by `CatalogTool`
  alike.
- `Upstream.client` does not validate certificates. Never send credentials through it.
- HTTPS proxy URLs name `local.codevoid.de`, not `127.0.0.1`. The certificate is issued
  for that name.
- State lives in `object` stores initialised in `WmsProxyApp`, persisted as lenient
  JSON. There is no database and there are no migrations before 1.0.

## Library and catalogue

- `app/src/main/assets/library.json` is curated by hand. The `usable` and `refused`
  counts are written by `tools/check-library.py --update "<entry name>"`, never typed.
- `app/src/main/assets/catalog.json` is generated by `CatalogTool`. Never edit it by
  hand. To run the tool locally:
  `./gradlew :tool:installDist && tool/build/install/tool/bin/tool [--all]`.
- A push that changes `library.json` makes the Catalogue workflow commit `catalog.json`
  and `docs/service-catalogue.md` back to the same branch. Pull before pushing to that
  branch again.
- In `docs/service-catalogue.md`, the text between `<!-- library:begin -->` and
  `<!-- library:end -->` is generated by `tools/service-list.py`. Everything else in that
  file is written by hand. A service that was checked and left out gets a row there,
  with the date and the reason.
- Adding a library entry usually touches `library.json`, `docs/service-catalogue.md` and
  an `Added` line in `CHANGELOG.md`.

## Conventions

- `CHANGELOG.md` follows Keep a Changelog. User-visible changes go under `[Unreleased]`.
- Dependency versions in `app/build.gradle.kts` carry comments explaining their pins.
  Read the comment before bumping a version.
